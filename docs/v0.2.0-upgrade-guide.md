# Upgrade Guide: v0.1.x to v0.2.0

- [MongoDB Atlas provider minimum version 2.15](#mongodb-atlas-provider-minimum-version-215)

## Org managed credential output rename (Breaking Change)

`modules/create` replaces the flat credential outputs with one sensitive object, `org_managed_credential`, so bootstrap secrets from `mongodbatlas_organization` are not confused with future rotatable module-owned credentials.

### Who is affected?

Affected: `modules/create` callers that read `public_key`, `private_key`, `client_id`, or `client_secret`.

Unaffected: `modules/existing` callers, and import-only flows that never used create credential outputs.

### Required action

Update HCL references to the nested fields:

```terraform
# Before
module "atlas_org" {
  source = "mongodb/organization/mongodbatlas//modules/create"
  # ...
}

provider "mongodbatlas" {
  client_id     = module.atlas_org.client_id
  client_secret = module.atlas_org.client_secret
}

# After
module "atlas_org" {
  source = "mongodb/organization/mongodbatlas//modules/create"
  # ...
}

provider "mongodbatlas" {
  client_id     = module.atlas_org.org_managed_credential.client_id
  client_secret = module.atlas_org.org_managed_credential.client_secret
}
```

Same path change applies for `public_key` and `private_key` under `org_managed_credential`.

### State migration

No state migration required. Outputs are not resources; update references and re-plan.

## MongoDB Atlas provider minimum version 2.15

v0.2.0 raises the required [`mongodbatlas` provider](https://registry.terraform.io/providers/mongodb/mongodbatlas/latest) constraint in the root module and all submodules from `~> 2.7` to `~> 2.15`. Provider 2.15 fixes a Service Account issue in the paying org when creating a new org, so earlier versions can fail org creation.

### Who is affected?

Affected: Deployments pinned to a `mongodbatlas` provider version below 2.15. `terraform init` fails with a version-constraint error until the provider is upgraded.

Unaffected: Deployments already on `mongodbatlas` 2.15 or later.

### Required action

Allow Terraform to select a compatible provider and re-run init:

```terraform
terraform {
  required_providers {
    mongodbatlas = {
      source  = "mongodb/mongodbatlas"
      version = "~> 2.15"
    }
  }
}
```

Then run `terraform init -upgrade` to download the new provider version. Review the [provider changelog](https://github.com/mongodb/terraform-provider-mongodbatlas/blob/master/CHANGELOG.md) for any resource-level changes between your current version and 2.15.

### Why the change?

Org-resource secrets created at organization create time are bootstrap-only. Naming them as flat `client_id` / `public_key` read like steady-state credentials and would clash with a future rotatable `current_credentials` output from a dedicated rotation workflow.
